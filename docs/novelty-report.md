# 題材重複調査レポート

> 調査日: 2026-08-15

## 候補題材

| 項目 | 内容 |
| --- | --- |
| 言語 | Java 21 |
| 題材名 | ThreadLocalの残留で別テナントの監査ログが混ざる |
| 契約 | 単一ワーカーでテナント`tenant-a`の処理後にテナント未指定の処理を実行しても、監査イベントは`tenant-a`へ帰属してはならず、`SYSTEM`になる必要があります。 |
| 原因 | `ThreadLocal`に設定したテナントIDをタスク終了時に`remove()`しないことです。 |
| 実境界 | JDKの`ExecutorService`上で順番に実行する公開ジョブAPIです。 |

## カタログ確認

`repository-catalog`の`refresh_catalog.py`と`validate_catalog.py`を2026-08-15に実行し、447件のリポジトリ、97件の学習用候補を検証しました。`check_catalog_overlap.py`による検索語`ThreadLocal, ExecutorService, thread pool, tenant, context, cleanup, audit log`の自動スクリーニング結果は「機械的な近接候補なし」でした。

自動検索だけでは新規性を断定せず、Javaの近接題材についてREADMEとテスト境界を手動で比較しました。

| 比較対象 | 直接原因 | 実境界 | 観測契約 | 最小修正 | 判定 |
